A static cybersecurity portfolio designed for GitHub Pages.

## What's included

- `index.html` — homepage
- `projects/kc7-security-analyst-1.html` — first KC7 case study
- `assets/style.css` — responsive styling

## Before publishing

1. Replace the placeholder LinkedIn link in `index.html`.
2. Replace the placeholder GitHub link in `index.html`.
3. Add your approved KC7 completion screenshot or badge.
4. Review KC7's current rules before publishing detailed solutions or spoilers.
5. Add your own investigation notes and findings to the case-study page.

## Publish with GitHub Pages

If your GitHub username is `example`, create a repository named:

`example.github.io`

Upload the contents of this folder to that repository.

Then open:

Settings → Pages → Build and deployment → Deploy from a branch

Choose the `main` branch and `/ (root)`.

Your site will be available at:

`https://example.github.io`
