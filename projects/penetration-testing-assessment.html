Scope

Controlled black-box testing

The exercise simulated an external assessment with no starting credentials or internal system knowledge. All activity was performed against a purpose-built academic target inside the authorised scope.

Public version

Target addresses, credentials, flags and exploit commands are intentionally omitted.

Method

Reconnaissance, validation, risk and remediation

01
Reconnaissance

Identify exposed services and the reachable attack surface.

02
Vulnerability assessment

Review discovered services and application behaviour for testable weaknesses.

03
Controlled validation

Validate selected findings within scope to demonstrate potential impact.

04
Risk analysis

Use CVSS and MITRE ATT&CK context to prioritise the findings.

Findings

Validated weakness categories

Default credentialsAdministrative access risk
SQL injectionBackend data exposure risk
Weak passwordsCredential-compromise risk
Exposed servicesAdditional attack surface requiring hardening
Remediation

Recommendations tied to the findings

•

Replace default credentials and enforce stronger password controls.

•

Use multi-factor authentication for critical or administrative access.

•

Use parameterised queries and appropriate input validation to reduce SQL injection risk.

•

Patch exposed services and reduce unnecessary attack surface.
