DIGITAL FORENSICS · 2024

Forensic disk investigation from image to timeline

A controlled academic investigation of a forensic disk image. I used evidence-integrity checks, artefact analysis and timeline reconstruction to produce traceable findings and a structured forensic report.

Primary toolsAutopsy · FTK Imager
EvidenceForensic disk image
MethodsHashing · carving · timeline
OutputForensic report
Case file01 Objective02 Integrity03 Analysis04 Workflow05 Reporting06 Lessons
01 / OBJECTIVE

Build conclusions that can be traced back to evidence

The investigation required examination of a supplied disk image to identify user activity, suspicious artefacts and relevant files while preserving the reliability of the evidence. The emphasis was not only finding artefacts, but recording how each conclusion was reached.

02 / EVIDENCE INTEGRITY

Validate before analysing

I compared cryptographic hash values associated with the forensic image to confirm that the evidence being examined matched the acquired image. This created a defensible starting point before interpretation.

Forensic principle

Evidence integrity and traceability are part of the analysis. A technically interesting artefact is not useful if the process cannot show where it came from and whether the evidence remained consistent.

04 / WORKFLOW

How I kept the investigation organised

01
Establish evidence details

Record image metadata, identifiers, tool versions and integrity values.

02
Survey the image

Review file-system structure, user areas, installed software and high-value artefact categories.

03
Investigate specific artefacts

Recover, hash and interpret relevant files rather than treating every artefact as equally important.

04
Build the timeline

Use timestamps and running-sheet notes to order activity and check whether separate artefacts support the same event sequence.

05
Report with traceability

Link findings back to source evidence and explain the security significance in clear language.

05 / REPORTING

Turn technical artefacts into an investigation record

I maintained a running sheet and created a structured report so the sequence of actions, evidence and conclusions could be followed. This improved accuracy and reduced the risk of losing context between individual artefacts.

✓

Separated observed evidence from interpretation.

✓

Used timestamps to connect activity across artefact types.

✓

Documented tool usage and evidence-integrity checks.

06 / LESSONS

What I learned

Digital forensics reinforced the importance of patience and traceability. The strongest finding is not the most dramatic file—it is the conclusion that can be reproduced from preserved evidence, documented steps and a clear timeline.
