DIGITAL FORENSICS · 2024

Forensic disk investigation from image to timeline

Controlled academic investigation of a forensic disk image using evidence-integrity checks, artefact analysis and timeline reconstruction.

ToolsAutopsy · FTK Imager
EvidenceForensic disk image
MethodsHashing · carving · timeline
OutputForensic report
On this page01 Objective02 Workflow03 Reporting04 Lessons
Objective

Trace conclusions back to evidence

The task was to identify relevant user activity and suspicious artefacts while preserving evidence integrity and documenting how each conclusion was reached.

Workflow

From validation to timeline

01
Validate the image

Check forensic-image metadata and hash values before analysis.

02
Review artefacts

Use Autopsy and FTK Imager to examine files, user activity and relevant metadata.

03
Recover and correlate

Apply carving, hashing and timestamp analysis to connect related evidence.

04
Build the timeline

Use running notes and timestamps to reconstruct the sequence of activity.

Reporting

Clear, reproducible findings

•

Separated observed evidence from interpretation.

•

Recorded tool use, integrity checks and relevant artefact sources.

•

Presented the final sequence in a structured forensic report.

Lessons

Traceability matters

The strongest forensic finding is not the most dramatic artefact. It is the conclusion that can be reproduced from preserved evidence, documented steps and a clear timeline.
